# Contributing

Add packages only with evidence of their function and affected features. Do not classify every vendor package as bloatware. Keep hardware services, accessibility, updates, authentication, and third-party apps protected.

For another TV model, propose a separate explicit profile rather than silently expanding this Xiaomi list. Include model/Android version, original package state, recovery steps, and which functions were exercised. Redact hardware serials, LAN addresses, account names, and personal app lists.

Run the unit tests. Test failures, connection interruption, absent packages, and restore behavior. Do not run live-device apply in CI. The current fake-device tests verify orchestration and recovery, not vendor behavior.
